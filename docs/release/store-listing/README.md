# Store listing drafts

Superseded in part on 2026-10-10: the name, subtitle, keywords, promotional text, description and screenshot plan to enter are now in [../app-store-listing.md](../app-store-listing.md), which rests on [the listing research](../../market/2026-10-10-app-store-listing-research.md). [listing.en.md](listing.en.md) and [screenshots.md](screenshots.md) are kept as the earlier draft; the worksheet still holds the App Store Connect answers.

These files are drafts of the SpacePane 1.0.0 Mac App Store listing and submission answers, written on 2026-10-10: the English text ([listing.en.md](listing.en.md)), a screenshot shot list with the checks each shot must pass ([screenshots.md](screenshots.md)), and the field-by-field App Store Connect answers ([app-store-connect-worksheet.md](app-store-connect-worksheet.md)). They are English only; no screenshot exists yet. The text in these drafts was not entered in App Store Connect: the text from [../app-store-listing.md](../app-store-listing.md) was, on 2026-10-10. The review notes themselves live in [../app-store-submission.md](../app-store-submission.md). Every claim in the text was checked against `docs/validation/host-matrix.json`, the format catalog and the entitlement files, and the text deliberately claims no Finder routing and no thumbnail for any named type (the matrix records Finder preview observed for 4 of 76 types, Finder thumbnails for none, all on development-signed builds). Open decisions that change these drafts: which interface languages ship in 1.0.0 and so which localized listings and screenshots are needed (D-B; the description has a marked `LANGUAGES` placeholder); the minimum macOS version (D-I, never run on macOS 15); the exact System Settings path, to be recorded on the store build; which Finder types are observed on the store build (this decides which screenshots and any sentences about Finder may exist); the regional variants for Portuguese and Spanish; base storefront and availability; the review contact details; the `.html` or extensionless form of the privacy and support URLs; and whether the 3D helper's source offer and notices are mentioned in the text once the About page shows them.
