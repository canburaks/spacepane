# Pending Mac verification queue

This is the queue that [decision 027](../decisions/027-best-in-class-quality-program.md) defines. Cloud sessions, which have no Swift toolchain, append one row for every commit that changes Swift, project configuration, string resources or anything else only a Mac can check. Mac sessions work the rows top to bottom, fix compile and test failures in place, record the outcome in a dated validation record under this directory, and only then check plan boxes and move the row to "Closed". A row is never closed by the session that wrote it.

Rules: one row per commit; the commands are exact; the observations say what to record, not what the author expects; a row that a Mac session cannot close in one sitting is split, not skipped. The queue is empty when the program is done.
