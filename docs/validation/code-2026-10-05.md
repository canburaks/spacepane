Branch `parity/code`, base `20acae7`. Design and limits are in [decision 019](../decisions/019-code-config-and-text-breadth.md). This record states what was run and what was not.

macOS on Apple silicon (Darwin 27.2), Xcode with Swift 6.4 selected, command-line SwiftPM build in Debug (`--build-system native`). No signed app, installed extension, Finder, `qlmanage`, `pluginkit`, Quick Look cache or user preference was touched.

## Tests added (158)

Under `Packages/PreviewCore/Tests/<Target>/Code/`.

- **PreviewFormatsTests:** language detection for 55 suffixes, 20 exact names, 9 interpreter lines and a reachability test that every one of the 84 language identifiers can be produced from a file name.
- **PreviewCoreTests:**
  - INI adapter: normal, `_authToken=`, `_auth=`, `_password=`, `.pypirc` `password =`, indented, backslash and CRLF continuations, an empty placeholder that must not hide later sections, URL credentials (host and user-only forms stay readable), `requirepass`-style directives (`proxy_pass` stays readable), bearer and provider tokens, no over-concealment of `bypass`/`compass`, whole-text concealment when ranges exceed the budget, budgets and cancellation.
  - Embedded secrets in code: connection strings, secret command-line flags, Dockerfile `ENV NAME value`, language from the name hint.
  - Logs: ten credential forms with neighbouring lines readable, a value-less prompt that conceals nothing else, secret-word stack frames keeping their line numbers, fake frames still concealed, bracketed values continuing until balanced, recognizable tokens, whole-text concealment on range overflow.
  - JSONC: ten lenient documents kept byte-exact, 22 malformed inputs, depth, node, size and line budgets, five key syntaxes concealed (comment text and delimiters), cancellation and an expired deadline.
  - Minified JSON: exact pretty layout, structural equivalence through `JSONSerialization`, key order, number lexemes and escapes preserved, duplicate keys, concealment carried to output ranges and through the privacy stage, line, output and structure limits.
  - Captions: each dialect's normal, malformed, limit and privacy cases, override-tag removal in the cue list only, MicroDVD frame conversion, VobSub and binary guards, cancellation and deadline for every adapter.
  - Partial reads through the real pipeline and files: cut at LF, CRLF, lone CR and a CR/LF split; UTF-8 multi-byte and UTF-16 LE/BE surrogate boundaries across every limit in a window; line-count and line-length cuts; blank-line cuts for SubRip; quoted-record cuts for CSV across 31 limits; exact-size and one-byte-over files; a single over-long record; structured formats (JSON, YAML, TOML, XML, notebook, env, JSONC), MicroDVD and non-capable readers still failing with `inputTooLarge`; disabled and cancelled partial requests; a secret and an unterminated key block in the prefix; files unchanged.
  - Catalog and pipeline: every new format has a descriptor and a registration; no suffix or name has two owners; Source Code covers at least 150 suffixes without reserved ones; lock files, Apple files, `tsconfig.*` and dotfile names classify as documented; disabled types are never read (reader count zero) and never fall back; cancellation precedes the read for nine suffixes; synthetic secrets never reach any new presentation; the minified-JSON path and notice flag through the pipeline; VobSub reports binary content.
- **PreviewRenderersTests:**
  - 22 tokenizer tests: C family, Swift, Rust, Python, JavaScript, SQL, shell, Lua, Haskell, Lisp, CSS, Dockerfile/HCL/Makefile/ignore/CMake, hardware, markup, Unicode ranges, budgets and surrogate pairs, the generic fallback, a well-formedness invariant (ordered, non-overlapping, in bounds) for all 84 languages against 40 hostile inputs and a linear-time check.
  - Line and caption tokens: ISO, syslog, Apache and bare times; severity mapping; frames, tracebacks, goroutines and crash frames; INI, JSONC, SubStation and the other caption dialects, with the same invariant for all eight new syntaxes.
  - Derived modes: INI outline, JSONC outline, cue rows for all five dialects, structure fallback on collapse, the String Catalog table and its limits, and the status-line notices (locale-formatted byte counts, all 14 languages resolve the new strings).
  - A native-view test showing different languages color the same characters differently.
- An existing test changed: `JSONLinesPipelineSharesCumulativeAndByteBudgets` asserted `inputTooLarge` for a file just over the budget and now asserts the partial result plus the failure when the first record cannot fit. `tools/test_localization.py` (formatted-key set) and `Tests/Integration/CompanionModelChecks.swift` (the Structured group's member list) each gained the new entries, because both hard-code catalog-derived lists.

## Measurements

Not measured in Release. The linear-time test decorates about 190 KB of Swift source in roughly a quarter of a second in a Debug build including test overhead; no memory or Release-configuration benchmark was recorded, so the plan's performance budgets remain targets.

## Not verified

- Finder routing of any new suffix or file name, and whether another installed provider wins; imported declarations were validated by the catalog and manifest checks only.
- Quick Look preview and thumbnail behavior in a signed host (including the `content` thumbnail policy of logs, drawn by the thumbnails workstream).
- VoiceOver, keyboard and copy behavior of the new Outline, Cues and Table views.
- Native-speaker review and translated layout of the 18 new strings (drafts).
- Behavior on a Mac with other apps declaring the same suffixes, and on macOS 15 specifically.
- Accuracy of every keyword table against its language's current specification: the profiles are lexical decoration and were tested for structure, not for completeness of each language's vocabulary.
