# Package, certificate, disk-image and torrent inspection validation — 2026-10-05

Decision: [package and certificate inspection](../decisions/017-package-and-certificate-inspection.md). Environment: Apple silicon, macOS 27.2, Xcode 27.0 (Swift 6.4), command-line SwiftPM and `script/build_and_run.sh`. Branch `parity/packages`, based on `20acae7`. Every fixture is synthetic: built in code or by `script/package_fixtures.py`; the only certificate is a self-signed example whose private key was discarded when it was created.

## Not verified

None of the following was observed, and none may be inferred from the results below.

- Finder or Quick Look routing for any of the eight types (`.app` directories, `.apk` and `.aab` in particular have no system type or may not reach a third-party extension), thumbnails, and the preview extension's behavior with the new formats in a signed host.
- The Security signing calls inside the Quick Look sandbox. The tests ran in an unsandboxed process; sandbox denial is handled by reporting "not available" but was not exercised.
- VoiceOver, keyboard navigation and visual layout of the Summary tree and the Icon view in any language, right-to-left rendering, and text expansion.
- Native-speaker review of the 128 new strings in 13 languages (all are drafts), and the effective language of a Finder-hosted extension.
- Real-world files: no real application, installer, profile, certificate, image, bundle or torrent from this Mac or the internet was used. Compatibility with the variety of real packers, signers and tools is therefore untested. Apple's size-optimized iOS PNGs (`CgBI`) were not available to test; the code omits an icon ImageIO declines.
- Performance on large inputs (multi-gigabyte images, installers or applications) and Release-configuration timings.
- Intel Macs and macOS versions other than 27.2.

## Known limits recorded by the tests

- An IPA, APK or AAB with more than about 3,000 members exceeds the shared ZIP reader's 1 MiB read allowance and reports "too large". Adapter-level listings stop at about 2,165 entries at the default budget and say so.
- An installer's table of contents above about 2,000 files fails with the structure limit instead of listing partially.
- A disk image whose partition table exceeds 768 KiB or the remaining allowance shows only the trailer facts, flagged partial.
- Torrents above the 1 MiB input budget are refused.
- Dates are shown as ISO 8601 text; they are not localized by the Summary view.
