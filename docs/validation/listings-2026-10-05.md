## Observed (Debug) timings

- 8,000-entry listing: parse, tree and Files table for the whole model in 0.5 s (test bound 5 s).
- Sorting a 20,000-row text column: 0.6 s including fixture creation (test bound 2 s).

## Not verified

- Finder routing, the Quick Look host window, folder thumbnails and any signed or sandboxed
  behavior (descriptor-relative traversal under the extension sandbox, folder access grants).
- VoiceOver speech (the sort announcement, labels and help text exist and are asserted as
  strings, not heard), keyboard behavior in a real Finder host, Dynamic Type and RTL layout.
- Native-speaker review of the 26 new strings in 14 languages (drafts; placeholders checked).
- Release-configuration performance, very large real folders, network or cloud volumes, and
  case-insensitive or Unicode-normalization edge cases on other filesystems.
- The `UF_HIDDEN` flag and `.hidden` files are intentionally not treated as hidden.
