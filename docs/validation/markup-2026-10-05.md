# Markup documents validation

Date: 2026-10-05 (Europe/Istanbul). Design and limits are in [decision 015](../decisions/015-markup-documents.md); the program is [decision 025](../decisions/025-competitor-parity-program.md). Everything below was observed on the development Mac with Apple Swift 6.4 (`arm64-apple-macosx27.2.0`, Xcode at `/Applications/Xcode.app`) in Debug builds, from the `parity/markup` worktree.

## What this record does and does not show

It shows that the Swift package, the native renderers driven through `NativePreviewView`, the shared pipeline and the generated manifests behave as specified for the six new formats, the extended Markdown renderer, the Contents and References views and their localization resources.

It does **not** show: Finder or Quick Look routing for any suffix or type, the signed extension, thumbnails (a separate workstream), VoiceOver behavior (labels and hints are asserted, not heard), keyboard behavior in a signed host (key events are synthesized against the view), installed-bundle localization lookup in a Finder host, native-speaker review of any of the 29 new strings in 13 languages (drafts only), Release-build performance, or any behavior on macOS 15 itself. No signed app, Xcode build, `qlmanage`, `pluginkit` or Finder interaction was run.

An earlier full run, before the last two changes, failed six expectations in the notebook renderer's tests, and that is how two incompatibilities were found and fixed: fenced code lines had moved to a new decoration the notebook tests do not know (they now keep the inline-code decoration, and the direction pass recognizes a wholly covered line), and a 256-run cap on emphasis pairing meant a pathological line no longer reached the decoration ceiling those tests exercise (pairing is now linear with one stack per delimiter character and a step bound). The notebook tests pass unchanged.

## Privacy evidence

- Synthetic secrets (`synthetic-secret-value`, `synthetic-host-matrix-secret`) never appear in `TextPresentation.text` for any of the forms above, and the extra Markdown and LaTeX suffixes share their format's rules.
- The renderers take only `TextPresentation.text`. Tests give them concealed text and assert the concealment token survives in Rendered, in Contents row text, in front-matter blocks and in every BibTeX style. The cross-module path (pipeline to renderer) is composed from those two proofs; there is no single test that runs both, because the renderer test target does not link the pipeline module and `Package.swift` is not owned by this workstream.
- Known fail-closed behavior: a triple-quoted TOML secret in front matter hides the rest of the document, because the shared assignment policy cannot bound it. A secret in a YAML block scalar hides only the metadata (tested).
